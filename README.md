# Pádel Nueva Atalaya - Gestión de correo

Página pública informativa de la aplicación interna utilizada por la Asociación de Vecinos San Cristóbal para gestionar correos relacionados con reservas e incidencias de las pistas de pádel de Nueva Atalaya.

La aplicación funciona de forma local y utiliza acceso autorizado a Gmail para leer, clasificar y responder determinados correos relacionados con la gestión de las pistas.
